# Slice 07 — Portable device configuration

- **Mission:** JACK-SLICE-07-PORTABLE-DEVICE-CONFIG
- **Baseline SHA:** cb5ee2ea943afdadb6d7dc1b6e75a5a92c812b1b
- **Scope:** replace embedded personal destinations with user configuration; preserve existing commands, transport, and installer behavior; add offline regression coverage and migration guidance.
- **Design:** fixed `$HOME/.config/jack/config`; literal KEY=VALUE parsing with four supported keys, blank lines and full-line comments. No source, eval, expansion, or dynamically named assignment. Reject duplicate/unsupported keys, empty/invalid values, and NUL bytes before connection operations. Missing device pairs remain independently usable; malformed configuration fails globally. ASCII usernames, canonical IPv4, and DNS/MagicDNS labels are accepted; IPv6, ports, and trailing dots are excluded.
- **Status:** reports configuration and reachable/unreachable/unknown separately; non-zero when either device is incomplete or unreachable/unknown or a required client is absent. Explicitly does not verify SSH authentication.
- **Files changed:** `bin/jack`, `scripts/dev-check.sh`, `scripts/setup-macos.sh`, `scripts/setup-workstation.sh`, `README.md`, `config.example`, this record. Installer edits are messages only; install/uninstall paths and system behavior are unchanged.
- **Local validation:** CachyOS Linux x86_64, kernel 6.18.55-2-cachyos-lts, Bash 5.3.20. `./scripts/dev-check.sh`: eight groups PASS (syntax, executable bits, help, argument rejection, offline status, configuration errors, routing, installer refusals). Cases cover missing files/pairs, empty values, malformed/duplicate/unsupported keys, SSH option injection, inert command substitution/backticks, control/NUL bytes, IPv4/DNS routing, comments, and no final newline. Isolated temporary HOME and minimal stub PATH; compare HOME against expected fixtures to detect writes. ShellCheck 0.11.0 clean for CLI and dev-check; six existing installer findings (four SC2155 and two SC2016) remain non-blocking. `git diff --check` passes; scan found no former personal destination values in source/docs.
- **Security boundaries:** no real SSH or Tailscale operations in validation, no setup installation paths, sudo, package installation, service/firewall changes, credentials, or SSH-policy changes. SSH remains one validated user@host argument. No E2E.
- **Known limitations:** macOS/Bash 3.2 runtime NOT_RUN for Slice 07; Bash 3.2-compatible constructs used, pending Product Owner Mac acceptance. Configuration validates syntax, not tailnet membership or SSH authorization; users must choose tailnet destinations. Existing OpenSSH configuration/policy remains authoritative. No discovery, onboarding, or automatic migration. Prior bootstrap Mac acceptance does not establish Slice 07 Mac acceptance.
