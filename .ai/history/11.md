# Slice 11 — Easy setup and first-run diagnosis

- **Mission / baseline:** JACK-SLICE-11-EASY-SETUP-FIRST-RUN; 4375889038a3705460da8c5200bd41376a8ac1a6. Clean main matched fetched origin/main; GitHub authentication/write access, required checks, squash-only auto-merge, and branch deletion verified. No admin bypass.
- **Baseline audit:** source-checkout installers linked into ~/.local/bin; upgrades implicitly followed checkout changes, with no documented upgrade/version path. Bash, SSH and connected Tailscale are connection requirements; Git obtains the checkout, Python discovery is optional. macOS installer unnecessarily required Homebrew even with Tailscale installed; Linux path required pacman. Both force-replaced existing links and edited shell profiles. Linux could install packages with sudo, enable tailscaled and Tailscale SSH without separate consent. Uninstall filtered profile lines globally, potentially removing user-managed entries. First-run gaps included missing PATH/config/prerequisites, no diagnostic command, and incomplete public support/security/release guidance.
- **Implementation / files:** `bin/jack` adds read-only doctor and actionable prerequisite errors, reusing structural status parsing with a state-only mode. `scripts/setup-macos.sh` and `scripts/setup-workstation.sh` use new `scripts/install-common.sh` for consented user-level symlink management. `scripts/dev-check.sh` adds doctor/installer cases. README adds diagnosis, prerequisites, source installation/upgrade/PATH, manual admin steps, uninstall and security guidance. CONTRIBUTING and WORKFLOW validation descriptions corrected to match safe installers; engineering gates remain. This record contains audit and pre-merge evidence.
- **Doctor:** reports running unversioned CLI, macOS or Arch/CachyOS detection, Tailscale CLI/daemon state, SSH presence, optional Python parser, and config validity/completeness without showing identities or raw status. Exit 0 = all PASS; 1 = any FAIL; 2 = WARN only. Missing/invalid config and required prerequisites fail with next actions; optional Python or an unused/incomplete second destination warns. Without Python, read-only native daemon status remains explicitly running/starting or unavailable, not exact connectivity verification. No peer pings, SSH, or writes.
- **Installer decisions:** keep a source-checkout link installation, not package/daemon provisioning. Explain requirements before consent; exact yes for link creation/removal, EOF/decline cancels, identical install is a no-op. Never force-replace user files/links or chmod repository source. Refuse unsafe parents/ownership/permissions; Linux verifies Arch/CachyOS ID and pacman presence. No package execution, sudo, service/SSH-policy changes, or profile rewriting. Existing config/keys/profiles remain; legacy PATH entries are left for manual inspection/removal. The small shared helper avoids divergent safety logic. Failed link creation can leave newly created directories; hostile same-user races are outside the guarantee.
- **Compatibility:** existing connection/setup/discovery behavior, four-key config, safe atomic config writer, manual fallback and discovery-free non-interactive setup retained. Optional parser state mode does not alter default peer parsing. macOS remains primary; Arch/CachyOS is the supported Linux installation path. No claim of general Linux or Windows support.
- **Validation:** CachyOS x86_64, Linux 6.18.55-2-cachyos-lts, Bash 5.3.20, actual Python 3.14.8. All 17 dev-check groups PASS, including the prior 15 plus DOCTOR and INSTALLER_SAFETY. Doctor fixtures simulate Darwin/Arch and unsupported Linux, missing/disconnected/malformed Tailscale, missing SSH/Python, broken Python, missing/malformed/valid/partial config, exit precedence, no value disclosure, and read-only HOME. Installer fixtures test macOS/Linux consent/EOF refusal, repeats, uninstall consent, user-managed file/link refusal, symlink-directory refusal, preservation of config/profile/key sentinels and unsupported Linux refusal. Real native link operations occur only in temporary HOME; privileged/package/SSH commands are tripwires and remain uninvoked. All setup/discovery regressions pass; ShellCheck 0.11.0 clean across all Bash files (old installer findings disappeared with removed unsafe paths); diff check passes. No real installation, live tailnet/SSH, or system changes performed.
