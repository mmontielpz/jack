# Slice 15B — Safe lifecycle CLI

Baseline: `6f26b417c09d93ac1cc12c0732fb7eab74a2bcbd`.
Branch: `feat/15b-safe-lifecycle-cli`.

## Scope and implementation

- Added `jack install` / `jack uninstall` and command-specific help. Both delegate
  to the existing platform scripts and shared installer; legacy entry points stay.
- Resolve the invoked CLI through at most 16 symlinks with portable readlink and
  physical directory resolution. Preserve spaces; reject missing, symlinked,
  non-owned or group/other-writable helpers and checkout directories. This checks
  local ownership/permissions, not cryptographic authenticity of source.
- Preview exact source and installation paths before consent. Matching install or
  absent uninstall is a no-op. Unknown entries are refused; removal rechecks the
  link after consent. Report directory/link failures without automatic cleanup.
- Doctor diagnoses missing/unsafe helpers, broken installation links and links
  belonging to another checkout. Exit meanings remain 0 pass, 1 fail, 2 warnings.
  A broken installed command requires diagnosis from an intact source checkout.
- Updated the guide with unreleased lifecycle behavior, separate from v0.1.0.
  Version remains 0.1.0 pending separate release preparation; no update command.

Files: `bin/jack`, `scripts/install-common.sh`, both `scripts/setup-*.sh`,
`scripts/dev-check.sh`, `docs/guide.md`, and this record.
